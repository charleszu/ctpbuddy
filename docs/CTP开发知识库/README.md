# CTP 开发知识库

面向 Agent 与开发者的 CTP（综合交易平台）系统化开发指南。按“先读章节、再查速查表”的方式使用。

> **资料定位与适用基线**：本库是通用开发指南和检索入口，不是官方权威，也不代表某一家期货公司或所有柜台环境。默认以 SDK 6.7.13（2026-02-25 构建）为整理基线；版本、交易所、期货公司参数和结算单版式差异必须回到实际环境核对。
>
> **资料分层/优先级**：①官方可读 HTML（[`../api-doc-html/`](../api-doc-html/)）及配套头文件/error.xml；②项目考证与冲突记录（[`../notes/`](../notes/)）；③本库 01~12 的通用指南；④13~16 速查表和17版本记录。层级越靠前越优先；本库不全文复制官方资料，不以当前代码行为反推真实 CTP。
>
> **双向导航**：本库链接到官方 HTML 和 notes；根 README、DESIGN、语义知识库提供返回本库的入口。官方 HTML 与 notes 原稿保持原样，不向其写入反向链接；从来源返回本库可使用本 README 或项目入口。深度考证遇到冲突先看 [`../CTP语义知识库.md`](../CTP语义知识库.md) 与 [`../notes/09-错单推送面与错误码对账.md`](../notes/09-错单推送面与错误码对账.md) 等来源笔记。
>
> **项目状态与真实样本边界**：项目当前进展、实现清单和回归结果只看根 [`../../README.md`](../../README.md) 与 [`../../DESIGN.md`](../../DESIGN.md)，本库不全文复制项目进度。有限真实账户/结算单样本及审计脚本在 [`../../tools/audit_real_accounts.py`](../../tools/audit_real_accounts.py) 和其默认外部目录中；样本结论标注环境与版式，不外推为普遍规则。

## 检索建议
- 每章均含：要点速查表 → 详细说明 → 标准流程 → 代码范例 → 常见坑（现象→原因→处理）→ 检查清单 → 关键词索引。
- 按标识符检索（如 `OnRtnOrder`、`OrderSysID`、`ErrorID`）直接全文搜索即可；章节内“关键词索引”含中英文同义词。
- 标注“（工程建议）”的条目是通用工程经验，非接口规定；07、10、17 等专题含有价值但未全量核验的覆盖层，阅读时仍须回到分层来源核对，不宣称“全读”。
- 版本相关结论以 6.7.13 为整理基线，旧版差异用“旧版API/新版API”标明；实际后台与柜台参数优先。
- 真实数据结论须标明交易日、账号、期货公司/环境和版式；无法推广时只保留为待核事项，不覆盖来源笔记。
