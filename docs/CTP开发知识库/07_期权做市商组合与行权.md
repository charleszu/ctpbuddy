# 07 期权、做市商、组合合约与行权

> 适用：CTP 期货期权版 API（v6.x，覆盖上期所/能源中心/大商所/郑商所/中金所/广期所）。股票期权版（v3.x）为独立版本，仅在 §2.1 做区分。
> 参考表见《13_API方法速查表》《14_错误码速查表》《15_枚举常量速查表》《16_结构体字段速查表》，枚举详见《15_枚举常量速查表》。

## 2. 详细说明

### 2.1 版本与品种范围

- **期货期权版 v6.x**（例 v6.6.9、6.7.13）：可交易六家期货类交易所的全部期货与期权。期权包括商品期权，以及中金所股指期权 IO(沪深300)、MO(中证1000)、HO(上证50)，后续还会有更多股指期权。
- **股票期权版 v3.x**（例 v3.7.0）：只能交易沪深证券交易所的 ETF/股票期权，不能交易股票/基金本身。需在期货公司另开股票期权账户，支持的期货公司仅二十余家。示例：上证50ETF 2026年7月到期、行权价3100元认购，代码 10011686。目前沪深交易所无个股期权，只有 ETF 期权；将来上市个股期权后同样可由该版本交易。
- 股指期权 ≠ 股票期权：

| 项目 | 期货期权 | 股票期权 |
|---|---|---|
| 交易所 | 六家期货交易所 | 沪深两个证券交易所 |
| 品种 | 商品期权、股指期权 | ETF 期权（个股期权暂无） |
| 标的物 | 商品期权→商品期货；股指期权→股指（不可直接交易） | 个股或 ETF |
| 交割 | 商品期权→期货（实物）交割；股指期权→现金交割 | 实物交割（买卖 ETF 份额） |
| 行权方式 | 商品期权→美式；股指期权→欧式 | 欧式 |
| 开户门槛 | 除原油外商品期权 10万元以上；原油和股指期权 50万元以上 | 50万元以上 |
| 交易日期 | T+0 | T+0 |

- 股票 ETF 期权可申请对不同期权持仓做组合/拆分（牛市看涨价差、跨式等）降低保证金；股指期权暂无此功能；部分商品期权支持组合。

### 2.2 合约代码命名规则

| 交易所 | 规则 | 示例 |
|---|---|---|
| 上期所 | 标的期货代码 + C/P + 行权价（标的代码=2位品种+4位年月） | `cu1408C56000`（行权价56000看涨） |
| 能源中心 | 同上期所风格 | `sc2508C520` |
| 郑商所 | 标的期货代码(品种+3位年月) + C/P + 行权价 | `SR301C5300`（标的 SR301、行权价5300看涨） |
| 大商所 | `品种+YYMM-C/P-行权价`，用“-”分隔 | `m1412-C-2700` |
| 中金所 | 同上 | `IO1412-C-2300`（2014年12月到期、执行价2300点沪深300看涨）；`MO2506-C-6100` |
| 广期所 | 与大商所风格一致，带“-” | `lc2603-P-150000` |

注：C=认购(看涨/Call)，P=认沽(看跌/Put)。实际解析应优先使用合约字段而非字符串拆解（工程建议）：`CThostFtdcInstrumentField` 中的 `ProductClass`(期权)、`OptionsType`、`StrikePrice`、`UnderlyingInstrID`、`UnderlyingMultiple` 等。期权类型/ProductClass 枚举见《15_枚举常量速查表》。

### 2.3 虚实值、权利金、行权价

- 虚值额（郑商所/大商所）：
  - 看涨虚值额 = Max((行权价 − 标的期货结算价) × 期权合约乘数, 0)
  - 看跌虚值额 = Max((标的期货结算价 − 行权价) × 期权合约乘数, 0)
  - 交易时段内标的结算价一律使用昨结算价。
- 中金所：
  - 看涨虚值额 = max((执行价 − 标的指数当日收盘价) × 合约乘数, 0)
  - 看跌虚值额 = max((标的指数当日收盘价 − 执行价) × 合约乘数, 0)
  - 交易时段内收盘价用昨收盘价。
- 买方付权利金，卖方收权利金并缴保证金。

### 2.4 期权保证金完整公式

#### 2.4.1 郑商所 / 大商所
```
每手卖方交易保证金 = 权利金 + max(标的期货合约保证金 − 期权虚值额/2, 标的期货合约保证金/2)
权利金(昨仓) = 期权昨结算价 × 期权合约乘数
权利金(新仓) = 价格(昨结算价/成交价，由 OptionRoyaltyPriceType 决定) × 期权合约乘数
标的期货合约保证金 = [标的结算价 × 期货合约乘数 × 标的期货交易所保证金率(按金额) + 标的保证金率(按手数)] × 基础商品乘数
```
- 委托冻结保证金时权利金一律用昨结算价。
- 终端只需计算权利金部分；`max(...)` 后半部分用昨结算价计算为不变量，可由 `ReqQryOptionInstrTradeCost` 的 `ExchFixedMargin` 直接取得。

#### 2.4.2 中金所
```
买权(看涨)卖方每手 = 权利金 + max(标的指数当日收盘价×合约乘数×保证金调整系数 − 虚值期权保证金优惠比率×虚值额,
                                   最低保障系数×标的指数当日收盘价×合约乘数×保证金调整系数)
卖权(看跌)卖方每手 = 权利金 + max(标的指数当日收盘价×合约乘数×保证金调整系数 − 虚值期权保证金优惠比率×虚值额,
                                   最低保障系数×执行价×合约乘数×保证金调整系数)
```
- 权利金规则同上（昨仓用昨结算价；新仓按 OptionRoyaltyPriceType）。`max` 括号内为不变量，取 `ExchFixedMargin`。

#### 2.4.3 上期所（含能源中心）
```
每手卖方交易保证金 = max{ 标的期货合约保证金 × Delta风险值 + 权利金, 期权最小保证金 × 期权合约乘数 }
权利金(昨仓) = max(期权昨收盘价, 昨结算价) × 期权合约乘数
权利金(新仓) = 价格(昨结算价/成交价) × 期权合约乘数
标的期货合约保证金 = [标的结算价×期货乘数×标的保证金率(按金额) + 标的保证金率(按手数)] × 期权基础商品乘数  (交易时段标的结算价用昨结算价)
```
- “期权最小保证金”无论昨仓还是新仓均取昨日结算发布值。
- 不变量：`ExchFixedMargin`（标的保证金×Delta）与 `ExchMiniMargin`（最小保证金×乘数）。

#### 2.4.4 CTP 统一归纳
```
交易所保证金(每手卖方) = MAX(权利金 + 交易所期权合约保证金不变部分(ExchFixedMargin), 交易所期权合约最小保证金(ExchMiniMargin))
投资者保证金(每手卖方) = MAX(权利金 + 投资者期权合约保证金不变部分(FixedMargin),   投资者期权合约最小保证金(MiniMargin))
权利金(昨仓) = (上期所? max(昨收盘, 昨结算) : 昨结算) × 合约乘数
权利金(新仓) = (昨结算价 或 成交价) × 合约乘数  —— 由 OptionRoyaltyPriceType 决定
```
- ExchMiniMargin/MiniMargin 除上期所外为 0。
- 投资者保证金算法与交易所一致，仅把交易所保证金率换成投资者保证金率。
- 买方不占保证金，仅付权利金。

#### 2.4.5 郑商所组合保证金优惠
1. 买入跨式或宽跨式组合：不收保证金。
2. 卖出跨式/宽跨式：保证金 = 卖认购与卖认沽保证金中较大者 + 另一部位权利金。
3. 备兑看涨/看跌：保证金 = 权利金 + 期货交易保证金。

（各所当前优惠以交易所最新规则为准；另有大商所组合保证金业务，见 §2.9。）

#### 2.4.6 手续费
- 计算同期货（按手/按金额，开仓/平仓/平今），另增**执行手续费**；`ReqQryOptionInstrCommRate` 查询（OpenRatioByMoney/OpenRatioByVolume/CloseRatioBy.../CloseTodayRatioBy.../StrikeRatioByMoney/StrikeRatioByVolume）。
- 手续费成交时收取；组合合约成交衍生的手续费规则同普通合约，**组合无手续费优惠**。

### 2.5 行权与放弃

具体业务规则以交易所为准。

#### 2.5.1 接口一览

| 指令 | 请求 | 错误响应 | 正确响应 |
|---|---|---|---|
| 行权/放弃申请 | `ReqExecOrderInsert` | `OnErrRtnExecOrderInsert`、`OnRspExecOrderInsert` | `OnRtnExecOrder` |
| 行权撤销 | `ReqExecOrderAction` | `OnErrRtnExecOrderAction`、`OnRspExecOrderAction` | `OnRtnExecOrder` |
| 期权自对冲 | `ReqOptionSelfCloseInsert` | `OnErrRtnOptionSelfCloseInsert`、`OnRspOptionSelfCloseInsert` | `OnRtnOptionSelfClose` |
| 自对冲撤销 | `ReqOptionSelfCloseAction` | `OnErrRtnOptionSelfCloseAction`、`OnRspOptionSelfCloseAction` | `OnRtnOptionSelfClose` |

查询：`ReqQryExecOrder`（已报入交易系统的申请指令）。

#### 2.5.2 申请指令
- 行权指令包括申请行权和放弃行权，均用 `ReqExecOrderInsert`，由 `ActionType` 区分：`THOST_FTDC_ACTP_Exec`（行权）、`THOST_FTDC_ACTP_Abandon`（放弃）。
- 美式期权买方在到期日及之前任一交易日可行权（到期日之前任一交易日的交易时间，以及到期日 15:30 之前提出申请）；欧式期权买方只能在到期日（=最后交易日）当天行权。

| 交易所 | 美式 | 欧式 |
|---|---|---|
| 中金所 CFFEX | — | 沪深300股指期权（IO；同理 MO/HO 为欧式） |
| 郑商所 CZCE | 白糖、棉花、PTA、甲醇、菜籽粕期权 | — |
| 大商所 DCE | 豆粕、玉米、铁矿石、液化石油气期权 | — |
| 能源中心 INE | 原油期权 | — |
| 上期所 SHFE | 橡胶、铝、锌期权 | 铜、黄金期权 |

- 非到期日对欧式期权申请，CTP 不做判断，报入交易所后返回“报单被拒绝，不在宣告期内”。
- **行权锁仓并冻结资金**：实际可行权仓位 = min(多头持仓 − 冻结持仓, 可用资金能支付行权权利金的仓位)。行权冻结的仓体现在 `StrikeFrozen`。
- **放弃行权锁仓但不冻结资金**，冻结的仓体现在 `AbandonFrozen`。
- 中金所目前不支持现货期权的相关行权指令，支持期货期权行权指令。
- 上期所行权开平标志可报 `THOST_FTDC_OF_CloseToday`（平今）、`CloseYesterday`（平昨）、`Close`（平仓）；报平仓时 CTP 按平昨仓处理。

#### 2.5.3 自动行权、放弃行权、取消到期日自动行权
- 交易所在到期日闭市后默认自动行权实值期权，虚值期权放弃。若不想行权某实值期权，可在最后交易日申请放弃行权。
- 上期所、能源中心、郑商所支持放弃行权。
- 中金所：现货期权不支持通过柜台（如 CTP）放弃行权，只能通过会服系统。
- 大商所：不支持放弃行权，只支持“取消到期日自动行权”。例：持有 10 手实值期权想放弃 2 手，需先取消到期日自动行权，再申报行权 8 手。取消方法：`ReqExecOrderInsert`，`Volume` 填 0；不校验数量、不冻钱不冻仓，只有到期日才能报入。

#### 2.5.4 撤销申请
- `ReqExecOrderAction`，`ActionType` 取 `THOST_FTDC_ACTP_Exec` 等；以 `FrontID + SessionID + ExecOrderRef + InstrumentID` 四个字段组合撤一笔申请。
- 6.7.2 起支持撤销其他席位发起的“取消到期自动行权”或“期权自对冲”指令；接收其他席位指令时 FrontID、SessionID 均为 0，撤销时填 0 即可。

#### 2.5.5 自对冲（期权对冲 / 行权后期货对冲 / 做市商留仓）
自对冲含义：向交易所申请将同一期权的多空头仓位，或期权行权/履约后形成的期货多空头仓位自我对冲掉。**郑商所和中金所的自对冲业务走会服系统，不经交易通道，CTP 不支持。**

1. **行权后期货自对冲**：期权买方（卖方）可申请对同一交易编码下行权后（履约后）双向期货持仓对冲平仓，数量不超过行权获得的期货持仓量；结果从当日期货持仓量扣除并计入成交量。
   - 多头（买方行权后）仍用 `ReqExecOrderInsert`，`CloseFlag = THOST_FTDC_EOCF_AutoClose`。
   - 空头（卖方履约后）用 `ReqOptionSelfCloseInsert`，`OptSelfCloseFlag = THOST_FTDC_OSCF_SellCloseSelfFuturePosition`。
2. **期权自对冲**：对同一交易编码下双向期权持仓对冲平仓，结果从当日期权持仓扣除并计入成交量。`ReqOptionSelfCloseInsert`，`OptSelfCloseFlag = THOST_FTDC_OSCF_CloseSelfOptionPosition`。
   - 支持指定数量 `Volume`，但对仓位和资金都不校验（无仓位也能申请），交易所盘后校验。修改手数的方式：`ReqOptionSelfCloseAction` 撤销后重新申请。
   - 上期所：仅普通投资者可申请；同一客户、同合约、同开平标志只维护一条记录，后续指令为更新操作（本地报单编号相同）。例：先申请自对冲 3 手再申请 5 手，交易所记录仍一条，手数为 5。
   - 大商所：普通投资者和做市商均可申请；按合约指定，不区分投机/套保，不指定数量，当日有效。
3. **做市商留仓**：交易所默认每日对做市商期权买卖仓位自对冲（平仓），可申请留仓当天不被自对冲。沿用 `ReqOptionSelfCloseInsert`，`OptSelfCloseFlag = THOST_FTDC_OSCF_CloseSelfOptionPosition`。目前仅上期所做市商支持留仓申请。

行权相关枚举（ActionType、OptSelfCloseFlag、ExecOrderCloseFlag 等）见《15_枚举常量速查表》。大商所行权优化二阶段、大商所组保等专项业务见 §2.9。

### 2.6 询价与做市商报价

#### 2.6.1 询价
- 发起：`ReqForQuoteInsert`，`ForQuoteRef` 非必填，可由核心自动生成。
- 询价价差限制（期货公司在柜台配置，示例，郑商所）：

| 最新价≥ | 价差 |
|---|---|
| 0 | 8 |
| 50 | 10 |
| 100 | 20 |
| 200 | 30 |
| 300 | 50 |
| 500 | 75 |

判断：①依最新价确定档位和最小价差；②计算买卖价差，须**大于**设置价差（等于也不行）；③通过才报交易所，否则 CTP 直接拒绝，提示“CTP：当前价差禁止询价”。
- 询价间隔：中金所、大商所、上期所由交易所限制；郑商所在 CTP 柜台控制。过频报“CTP：当前时间禁止询价”。
- 中金所询价支持交易编码类型：投机、套保、套利。
- 响应：

| 回调 | 说明 |
|---|---|
| OnRspForQuoteInsert | 仅录入错误（字段校验失败、被限制询价等） |
| OnRtnForQuoteRsp（交易 SPI） | 暂不用 |
| OnRtnForQuoteRsp（行情 SPI） | 录入成功后推送，需先调用行情 API `SubscribeForQuoteRsp` |
| OnErrRtnForQuoteInsert | 交易所拒绝 |

- 中金所/上期所/大商所询价来自交易所交易流，郑商所来自行情流：仅连行情前置只能看到郑商所询价通知；连行情 front 可收到所有交易所询价通知。
- 查询：`ReqQryForQuote` → `OnRspQryForQuote`。

#### 2.6.2 报价
- 录入：`ReqQuoteInsert`（`CThostFtdcInputQuoteField`）；`QuoteRef`、`AskOrderRef`、`BidOrderRef` 非必填，手填时要求 AskOrderRef < BidOrderRef，否则报“CTP：重复的报单”。
- **上期所期货合约用 `ReqOrderInsert` 报价。**
- 响应：

| 回调 | 说明 |
|---|---|
| OnRspQuoteInsert | 仅录入错误（字段校验、无做市商权限等） |
| OnRtnQuote | 录入成功后的报价响应 |
| OnRtnOrder | 双边报价时衍生出买、卖两笔衍生单入交易所并回报 |
| OnRtnTrade | 衍生单成交回报 |

- 撤报价：`ReqQuoteAction`，用 `QuoteRef+SessionID+FrontID`。撤衍生单：`ReqOrderAction`，用 `FrontID+SessionID+OrderRef`；若报价时未填 AskOrderRef/BidOrderRef，衍生单 OnRtnOrder 中 FrontID、SessionID 为 0。
- 查询：`ReqQryQuote` → `OnRspQryQuote`。
- 状态维护差异：大商所接受报价后不再维护报价状态，报价状态没有完整生命周期，须关注衍生报单状态；上期所维护报价状态但与报单状态独立（两腿都已成交仍可撤报价且成功）；中金所报价/撤报价时交易所发送 OnRtnQuote（置已撤销），但单独撤销两个衍生单后不再更新报价状态。

### 2.7 组合合约（期货套利合约）

- 又称套利合约，由两条腿组成：跨期（同品种不同交割月，近月=第一腿）、跨品种（不同品种同交割月，乘数相同，如玉米-玉米淀粉、黄豆一号-豆粕）。
- 代码规则：

| 类型 | 格式 | 示例 |
|---|---|---|
| 郑商所跨期 | `SPD 第一腿&第二腿` | `SPD TA011&TA101` |
| 郑商所跨品种 | `IPS 第一腿&第二腿` | `IPS CF101&CY101` |
| 大商所跨期 | `SP 第一腿&第二腿` | `SP m2101&m2105` |
| 大商所跨品种 | `SPC 第一腿&第二腿` | `SPC a2101&m2105` |

  含空格与`&`，处理时需注意。
- 合约信息（`ReqQryInstrument`）：以 `SPC a2101&a2105` 为例：ProductID=`SPC a&a`，ProductClass=`THOST_FTDC_PC_Combination`，VolumeMultiple=0，PriceTick=1.0，ExpireDate 空，DeliveryYear/Month=0（单腿则有值）。
- 行情：可订阅，但最新价、成交量等为 1.7976931348623157e+308（double 上限，即无效值），需用两腿行情自行合成。
- 报单：与普通合约基本相同；**不支持市价单**；买入组合=买第一腿+卖第二腿，卖出组合=卖第一腿+买第二腿；价格可为负（如 -10）。
- 成交：两腿同步成交，分别收到两条 `OnRtnTrade`（顺序不定），两腿成交价差等于或优于报单价；可部分成交，但两腿数量始终同步；`TradeType = THOST_FTDC_TRDT_CombinationDerived`。
- 平仓校验：判断的是两条腿对应方向的可用单腿持仓是否足够，而非组合持仓数；即使无组合持仓，也可用组合合约平掉两个单腿持仓（A多10手、B空7手，下单A&B最多卖平7手）。
- 手续费无优惠。

#### 2.7.1 组合持仓计算规则

**开仓**：持仓查询生成 3 条记录：组合合约持仓 + 两条腿持仓。近月腿方向与组合一致，远月腿相反。
- 组合持仓记录只计算：上日持仓、今日持仓、总持仓、开仓量、保证金；平仓量、平仓盈亏、持仓成本、持仓盈亏、手续费都在分腿中。
- 分腿记录：上日/今日/总持仓、开仓量、平仓量为单一+组合持仓**总和**，需查持仓明细区分；分腿保证金字段只含单一合约持仓保证金，组合保证金存放于组合记录；开仓成本、均价、持仓成本、持仓均价、持仓盈亏、平仓金额、平仓盈亏、手续费涵盖所有持仓。
- `CombPosition` 表示单腿持仓中由组合成交产生的手数。

**平仓**：原则“先单一后组合，先开先平”。使用组合头寸时需“打散”：自身分腿的组合持仓量减少、平仓量增加；组合记录持仓量减少；另一分腿的组合头寸减少并衍生出单一持仓（量=平组合量，撮合编号与开仓时间与原组合一致）。

示例（A、B为腿）：
1. 单一合约平仓用到单个组合头寸：A单一4、AB组合2；B单一3、AB组合2。平A 5手：A单一全平4，再打散AB组合1手 → A单一0、AB组合1；B单一4(衍生1)、AB组合1。
2. 用到多个组合头寸：A单0，AB组合1；B单3，AB1，BC7(AB先开)；C单0，BC7。平B 5手：先平单一3，再打散AB 1手，再打散BC 1手 → A单1、AB0；B单0、BC6；C单1、BC6。
3. 平组合只用自身头寸：A单0，AB组合4；B单1，AB组合4。平AB 3手：A腿成交时打散AB 3手；B腿同时衍生3手单一，因开仓时间早于原1手单一，先平衍生的3手 → A单0、AB1；B单1(原有)、AB1。
4. 用到其他组合头寸：A单1，AB2；B单0，AB2，BC3(BC先开)；C单1，BC3。平AB 1手：A用单一；B无单一，打散BC 1手 → A单0、AB2；B单0、AB2、BC2；C单2、BC2。
5. 用单一头寸：A单2，B单1，AB0。平AB 1手可行，两腿均用单一 → A单1、B单0。
6. 用多个组合（其他及自身）：A单0，AB2；B单0，AB2，BC2(AB先开)；C单2，BC2。平BC 3手：B腿先打散AB 2手(A衍生2单一)，再平BC 1手(C衍生1单一)；C腿3手单一全平 → A单2、AB0；B单0、BC1；C单0、BC1。

**冻结**：体现在组合记录的 `LongFrozen/ShortFrozen`，及分腿的 `CombLongFrozen/CombShortFrozen`。多头开仓冻结：组合 LongFrozen 增，近月腿 CombLongFrozen 增，远月腿 CombShortFrozen 增。多头平仓冻结：组合 ShortFrozen 增、可平数量减，近月腿 CombShortFrozen 增，远月腿 CombLongFrozen 增。

**查询**：持仓汇总返回 3 条；组合记录基本只有 UseMargin 与各数量字段(Position、YdPosition、LongFrozen 等)有意义；两分腿保证金为0。持仓明细 `TradeType` 即开仓成交类型，可判断是否组合衍生；平仓时持仓明细更新较复杂，甚至可能平仓时凭空增加一条明细记录。专用接口：`ReqQryInvestorPositionCombineDetail` → `OnRspQryInvestorPositionCombineDetail`，`CThostFtdcInvestorPositionCombineDetailField`。

#### 2.7.2 各所套利指令
| 所 | 支持 |
|---|---|
| 上期所 | 无 |
| 大商所 | 跨期、跨品种（交易所提供规范合约）；展期(同品种不同月)、互换(不同品种同月)，CTP 报单录入时 `IsSwap = true` |
| 郑商所 | 跨期、跨品种（交易所提供规范合约） |
| 中金所 | 暂无（未来计划开放 期货×期货、期货×期权、期权×期权组合保证金） |

### 2.8 强平、强减、风控

- 强平=强制平仓（斩仓）：常见于客户权益为负，期货公司通知后限期未平则强平；另一常见场景是自然人持有商品期货持仓将进入交割月。
- 强平/强减单仍需进入交易所撮合队列，可能长期不成交。
- 下单可设强平标志 `UserForceClose`，但期货公司通常不允许（难以区分来源）。
- 回报 `CThostFtdcOrderField.ForceCloseReason`：

| 值 | 宏 | 含义 |
|---|---|---|
| '0' | NotForceClose | 非强平 |
| '1' | LackDeposit | 资金不足 |
| '2' | ClientOverPositionLimit | 客户超仓 |
| '3' | MemberOverPositionLimit | 会员超仓 |
| '4' | NotMultiple | 持仓非整数倍 |
| '5' | Violation | 违规 |
| '6' | Other | 其它 |
| '7' | PersonDeliv | 自然人临近交割 |

- 开平标志 `THOST_FTDC_OF_ForceClose` 不能主动报入，会被 CTP 或交易所拒单（SimNow 实测被拒）。
- 穿仓：权益为负且无法通过平仓补足时的情形（工程建议：监控 `DynamicRights`/`Available<0` 并预警）。

### 2.9 到期日与交割
- 期权到期：到期日见合约 `ExpireDate`；最后交易日见 `ExpireDate`/行权日规则，实际以交易所公告为准；组合合约 ExpireDate 为空。
- 自然人不得持有交割月商品期货（将被强平，原因码7）。
- 大商所组合保证金、行权优化二阶段业务等见对应 API 页面“大商所组保”“大商所行权优化二阶段业务”。

## 3. 标准流程/时序

### 3.1 询价—报价
```
买方: ReqForQuoteInsert → OnRspForQuoteInsert(仅错) / OnErrRtnForQuoteInsert
行情SPI: (已 SubscribeForQuoteRsp) OnRtnForQuoteRsp → 做市商收到询价
做市商: ReqQuoteInsert → OnRspQuoteInsert(仅错) → OnRtnQuote
        → 两笔衍生单 OnRtnOrder(买/卖) → 成交 OnRtnTrade
撤: ReqQuoteAction(QuoteRef+SessionID+FrontID)
```

### 3.2 行权
```
ReqExecOrderInsert → OnRtnExecOrder(状态更新) / OnErrRtnExecOrderInsert
撤销: ReqExecOrderAction
```

### 3.3 组合开平
```
ReqOrderInsert(InstrumentID="SPD TA011&TA101", LimitPrice) → OnRtnOrder → 两腿 OnRtnTrade(TradeType=CombinationDerived)
```

}

## 5. 常见坑与排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 询价报“当前价差禁止询价” | 买卖价差不大于柜台配置价差 | 价差须严格大于配置值 |
| 询价报“当前时间禁止询价” | 询价过频 | 降低频率 |
| 报价“重复的报单” | 手填 AskOrderRef ≥ BidOrderRef | 保证 Ask<Bid，或留空 |
| 报价“报单字段有误” | 中金所/郑商所/上期所单边报价；郑商所/上期所双边数量不等 | 双边等量 |
| 郑商所套保报价被拒 | 期权仅支持投机 | 用投机 |
| 衍生单 FrontID/SessionID=0 | 未填 Ask/BidOrderRef | 手填并自行跟踪 |
| 大商所报价状态不更新 | 交易所不维护 | 看衍生单状态 |
| 组合合约行情最新价为极大值 | 无效值 | 两腿合成 |
| 组合市价单被拒 | 不支持 | 限价 |
| 组合持仓分腿保证金为0 | 保证金在组合记录 | 汇总计算 |
| 强平开平标志报入被拒 | 不可主动报入 | 不要使用 |
| 获取不到全部持仓费率 | InstrumentID 非空 | 置空查全部 |

## 6. 检查清单
**Do**：用 ProductClass 识别组合；用 ReqQryOptionInstrTradeCost 取不变量；卖方保证金用 MAX 形式；做市前订阅 SubscribeForQuoteRsp；组合平仓按“先单一后组合先开先平”维护明细。
**Don't**：不要主动报 ForceClose；不要对组合发市价单；不要假设各所报价状态语义一致；不要把代码字符串规则硬编码解析所有交易所。
