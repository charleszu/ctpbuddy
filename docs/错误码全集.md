## API 本地返回码（error.xml 不含，照 API 文档录）

真实 CTP 在 API 层先于柜台校验返回负数码，CTPBuddy 在适用的 shim/核心路径同步返回，客户端必须先处理它们；认证重复/断线失败的回调不伪装负数官方码：

| rc | 官方含义 | CTPBuddy 触发点 |
|---|---|---|
| -3 | 每秒发送请求数超过许可数 / 未登录 | 未登录即请求（报单、撤单、查询、订阅、登出、确认各面先判会话） |
| -2 | 未处理请求超过许可数 | 未认证（先 AUTH）/ 报单·撤单·登录·登出·确认·订阅字段长度错误 / shim 在途请求超许可 |
| -1 | 网络故障 | 非认证通用本地路径；认证断线不使用 -1，认证回调采用 `63 AUTH_FAILED`，网络原因由 `OnFrontDisconnected` 报告 |
