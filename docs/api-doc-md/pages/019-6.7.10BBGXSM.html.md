# 6.7.10版本更新说明

6.7.10版本更新说明

版本号：v6.7.10_20250422 16:38:54.9994

后台版本：V6.7.10

变更说明：（请各终端厂商根据自身情况进行开发）

◇ 1. API变动

◇ 1.1.CThostFtdcTradingAccountField、CThostFtdcInvestorPositionField增加“期权市值（OptionValue）”字段。

涉及接口包括：

[OnRspQryTradingAccount](JYJK/CTHOSTFTDCTRADERSPI/ONRSPQRYTRADINGACCOUNT.html)：请求查询资金账户响应

[OnRspQrySecAgentTradingAccount](JYJK/CTHOSTFTDCTRADERSPI/ONRSPQRYSECAGENTTRADINGACCOUNT.html)：请求查询二级代理商资金账户响应

[OnRspQryInvestorPosition](JYJK/CTHOSTFTDCTRADERSPI/ONRSPQRYINVESTORPOSITION.html)：请求查询投资者持仓响应

期权市值=（多头期权手数-空头期权手数）*期权合约乘数*期权最新价

终端厂商可通过期权市值计算市值权益：市值权益=期权市值+权益。
