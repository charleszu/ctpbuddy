OnErrRtnRepealFutureToBankByFutureManual<a id="content"></a>

<a id="left_menu"></a>

系统运行时期货端手工发起冲正期货转银行错误回报, 发起冲正后系统的报错回报，由于发起冲正属于ctp内部操作，没有req接口

TradeCode：203002 期货发起冲正期货转银行

BankID：银行在ctp对应的代码

BankBranchID：填0000

BrokerBranchID：一般为空

BankPassWord：返回银行的密码，都是“*”密码不显示

Password：返回期货账户的密码，都是“*”密码不显示

pRspInfo：响应信息
