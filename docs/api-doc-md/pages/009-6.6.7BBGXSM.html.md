<a id="header_span2"></a>◇ 1.1. 新增CTP_GetDataCollectApiVersion接口

<a id="header_span3"></a>◇ 1.2. [SubmitUserSystemInfo](pages/155-JYJK-CTHOSTFTDCTRADERAPI-SUBMITUSERSYSTEMINFO.html.md)增加错误返回
<a id="panel3"></a>

[SubmitUserSystemInfo](pages/155-JYJK-CTHOSTFTDCTRADERAPI-SUBMITUSERSYSTEMINFO.html.md)函数增加错误返回值：-7，对应错误信息为“api and collect api version dismatch  ”

采集库版本与API版本不匹配时输出该错误码（举例采集库为评测版，API为生产版）
<a id="d38ebed6-a1ed-4af9-bb5c-73a2be8737a2"></a><a id="title4"></a>

<a id="header_span4"></a>◇ 1.3. CTP_GetSystemInfo增加返回值错误码
<a id="panel4"></a>

DATA_COLLECT_API_EXPORT int CTP_GetSystemInfo(char* pSystemInfo, int& nLen)在调用采集信息上报的时候，增加检查密文长度是否正常，不正常直接返回错误。长度大于等于264则放过。获取AES加密和RSA加密的终端信息pSystemInfo的空间需要调用者自己分配至少270个字节。

```
Windows返回值定义：
    返回值 & （0x01 << 0） 不为0 表示终端类型未采集到
    返回值 & （0x01 << 1） 不为0 表示 信息采集时间获取异常
    返回值 & （0x01 << 2） 不为0 表示ip 获取失败  （采集多个相同类型信息的场景有一个采集到 即表示采集成功）
    返回值 & （0x01 << 3） 不为0 表示mac 获取失败
    返回值 & （0x01 << 4） 不为0 表示 设备名 获取失败
    返回值 & （0x01 << 5） 不为0 表示 操作系统版本 获取失败
    返回值 & （0x01 << 6） 不为0 表示 硬盘序列号 获取失败
    返回值 & （0x01 << 7） 不为0 表示 CPU序列号 获取失败
    返回值 & （0x01 << 8） 不为0 表示 BIOS 获取失败
    返回值 & （0x01 << 9） 不为0 表示 系统盘分区信息 获取失败
Linux返回值定义：
    返回值 & （0x01 << 0） 不为0 表示终端类型未采集到
    返回值 & （0x01 << 1） 不为0 表示 信息采集时间获取异常
    返回值 & （0x01 << 2） 不为0 表示ip 获取失败  （采集多个相同类型信息的场景有一个采集到 即表示采集成功）
    返回值 & （0x01 << 3） 不为0 表示mac 获取失败
    返回值 & （0x01 << 4） 不为0 表示 设备名 获取失败
    返回值 & （0x01 << 5） 不为0 表示 操作系统版本 获取失败
    返回值 & （0x01 << 6） 不为0 表示 硬盘序列号 获取失败
    返回值 & （0x01 << 7） 不为0 表示 CPU序列号 获取失败
    返回值 & （0x01 << 8） 不为0 表示 BIOS 获取失败

```

<a id="header_span5"></a>◇ 1.4. 新增命令获取云服务器硬盘序列号信息
<a id="panel5"></a>

新增system("wmic diskdrive get serialnumber")命令获取CPU、硬盘序列号等信息。
<a id="f4a62cc8-9eb0-4f46-b3c6-560672d189b6"></a><a id="title6"></a>

<a id="header_span6"></a>◇ 1.5. 启用[OnHeartBeatWarning](pages/222-JYJK-CTHOSTFTDCTRADERSPI-ONHEARTBEATWARNING.html.md)心跳超时回调
<a id="panel6"></a>

当60s没有收到心跳时，支持回调该函数，客户端可提前知道网络断开等场景（前提是客户端需要实现该接口）。
<a id="20c750c8-c203-4e2d-933d-ea7ad2f0846b"></a><a id="title7"></a>

<a id="header_span7"></a>◇ 1.6. [OnRspQryInvestor](pages/259-JYJK-CTHOSTFTDCTRADERSPI-ONRSPQRYINVESTOR.html.md)和[OnRspQryProduct](pages/274-JYJK-CTHOSTFTDCTRADERSPI-ONRSPQRYPRODUCT.html.md)接口新增字段
<a id="panel7"></a>

[OnRspQryInvestor](pages/259-JYJK-CTHOSTFTDCTRADERSPI-ONRSPQRYINVESTOR.html.md)和[OnRspQryProduct](pages/274-JYJK-CTHOSTFTDCTRADERSPI-ONRSPQRYPRODUCT.html.md)接口新增频繁报撤单和日内开仓限制相关字段。具体限制的阈值请咨询期货公司柜台设置。
