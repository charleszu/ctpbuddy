```
    TThostFtdcIndividualNameType CustomerName;

    TThostFtdcIdentifiedCardNoType IdentifiedCardNo;

    TThostFtdcCustTypeType CustType;

```

TradeCode：102002 银行发起期货资金转银行

BankBranchID：填0000

BrokerBranchID：一般为空

BankPassWord：为密文，显示为“*”

Password：为密文，显示为“*”

InstallID：CTP内部使用

TransferStatus：查看转账成功与否的标志，“正常”则为转账成功，“被冲正”则为转账失败

ErrorMsg：返回的错误信息，成功则显示“交易成功”
