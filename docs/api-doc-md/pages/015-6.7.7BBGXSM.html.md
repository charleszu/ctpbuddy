◇ 1.5. 报单、报价录入请求响应ErrorMsg新增报单欠缺资金。

[OnRspOrderInsert](JYJK/CTHOSTFTDCTRADERSPI/ONRSPORDERINSERT.html)报单录入请求响应和[OnRspQuoteInsert](JYJK/CTHOSTFTDCTRADERSPI/ONRSPQUOTEINSERT.html)报价录入请求响应ErrorMsg新增报单欠缺资金。

当报单、报价资金不足时，返回的ErrorMsg中包含了欠缺资金，即：资金不足，约缺少资金[******]

◇ 1.6. 如下四个接口新增入参

[ReqOrderInsert](JYJK/CTHOSTFTDCTRADERAPI/REQORDERINSERT.html)（报单录入请求）、[ReqOrderAction](JYJK/CTHOSTFTDCTRADERAPI/REQORDERACTION.html)（报单操作请求）、[ReqQuoteInsert](JYJK/CTHOSTFTDCTRADERAPI/REQQUOTEINSERT.html)（报价录入请求）、[ReqQuoteAction](JYJK/CTHOSTFTDCTRADERAPI/REQQUOTEACTION.html)（报价操作请求）
