字段 取值 含义说明
LimitPrice 保护价 报单成交价不劣于该价格
VolumeCondition AV 任何数量，对应市价 FAK
VolumeCondition CV 全部数量，对应市价 FOK
VolumeCondition MV 最小数量，按指定最小数量成交，剩余部分撤销
